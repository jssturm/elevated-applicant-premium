# Elevated Applicant Premium Releases

Private distribution repository for approved Elevated Applicant Premium users.

## Current status

Premium modules have not been published yet. This repository initially holds only release artifacts, checksums, and installation documentation.

## Distribution boundary

- The public Free edition is distributed from [`jssturm/Elevated-Applicant`](https://github.com/jssturm/Elevated-Applicant).
- Premium releases may contain only newly authored modules whose distribution rights are documented.
- Existing MIT-licensed Free and contributor code remains under its existing license and is not reclassified as proprietary here.
- Release artifacts must be versioned and accompanied by SHA-256 checksums and edition metadata.
- User-owned files—CVs, profiles, application data, reports, and generated output—must never be included in release artifacts.

## Access

Repository access represents current Premium approval:

- Granting access allows the approved account to download Premium releases.
- Removing access blocks future Premium downloads.
- On a definitive access-revocation result, the app updater returns the installation to the public Free edition without deleting user data.
- Network, rate-limit, and server failures are not treated as revocation.

## Releases

Premium artifacts will be published through GitHub Releases. Do not commit generated archives, credentials, customer data, or installation tokens to the repository.
